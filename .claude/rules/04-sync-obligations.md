# 문서 동기화 · 용어집 · 대외비 필터링 · Git 배포 원칙

## WMS_docs 필수 동기화

- `PM_정답지_백업`에서 팀원 공유용(배포용) 문서를 생성/최신화하면, 작업 직후 **즉시**
  `E:\취업\KT AIVLE School\빅프로젝트\WMS_docs`에 복사하여 이원화 동기화를 완료한다.
- 한쪽 폴더에만 문서를 갱신하고 끝내지 않는다 — 두 폴더 상태가 항상 일치해야 한다.

## 대외비 필터링 (동기화 시 필수)

- `PM_정답지_백업` → `WMS_docs`로 문서를 동기화(복사)할 때, 원본에 "대외비", "핵심 알고리즘",
  "보안 등급", "Confidential" 등 기밀 로직이 포함되어 있으면 **그대로 복사하지 않는다.**
- 배포용으로 옮기기 전 기밀 내용을 삭제하거나 요약한 **"배포용 편집본"**을 별도로 만들어
  `WMS_docs`에 반영한다.

## Git(백엔드 레포 docs 폴더) 동기화 원칙

- Git 레포의 `docs` 폴더를 먼저 업데이트하거나 `WMS_docs` 전체를 통째로 복사/덮어쓰기
  하는 것을 엄격히 금지한다.
- 순서: ① `WMS_docs`와 `PM_정답지_백업`에서 배포용/대외비 문서 작성·최신화를 완전히
  끝낸다 → ② 그중 Git 공유에 실제로 필요한 파일만 선별하여 `docs` 폴더로 복사(업데이트)한다.

## 이중 교차 검증 (Double Cross-Validation)

- 코드나 문서의 대규모 수정·일괄 업데이트 작업은 단일 작업으로 끝내지 않는다.
- 작업 완료 후 `grep`/`grep_search` 등으로 변경 대상 키워드를 재검색하여, 누락된 잔재
  (예: 갱신되지 않은 옛 용어, 옛 버전 번호, 갱신 안 된 Mermaid 블록)가 없는지 반드시
  두 번째 패스로 확인한다.
