# Vision AI 테스트용 원시 데이터 (100장 샘플 이미지)

이 디렉토리는 홍경표(AI) 님의 Vision Agent가 GPT-4o(또는 동급 Vision LLM) 기반 훼손 탐지 파이프라인(PoC)을 테스트하기 위한 **도서 훼손 샘플 이미지 보관소**입니다.

## 📂 디렉토리 구조 (단일 폴더)
과거의 YOLO 방식처럼 라벨링(BBox XML)이나 등급별 폴더 사전 분류(MINT/GOOD 등)가 **전혀 필요 없습니다.** 

소한민 님께서는 확보하신 100장의 '날것(Raw)' 도서 이미지를 아래 폴더에 통째로 넣어주시면 됩니다.

* `/raw_inputs`: 모든 원본 도서 사진을 저장하는 폴더 (아무 분류 없이 통째로 보관)

## 📌 파일 명명 규칙 (Naming Convention)
AI가 결과를 출력할 때 어떤 책인지 식별만 가능하면 되므로, ISBN 정도만 기재해 주셔도 무방합니다.
* 예시: `9788937460753_1.jpg`
* 예시: `9788937460753_2.jpg`

## 🚀 향후 워크플로우 (Zero-shot API 추론)
이 폴더에 날것의 사진 100장이 세팅되면, 홍경표 님의 LangGraph `Vision Agent`가 이 폴더의 이미지를 순차적으로 읽고 Base64로 변환한 뒤, **Vision API(LLM)**에 던져서 제로샷(Zero-shot)으로 훼손 부위 문맥 추출 및 상태 추론을 수행하게 됩니다. 소한민 님의 데이터 가공 노력이 획기적으로 줄어듭니다!
