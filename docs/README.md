# docs

이 폴더에는 **런타임이 실제로 사용하거나 이 리포에서만 쓰는 자료**만 둡니다.

| 경로 | 내용 | 성격 |
| --- | --- | --- |
| `ai_knowledge_base/` | 검수 정책 YAML · WMS 표준 운영 정책서 | **런타임 사용** — RAG 임베딩 소스 |
| `policies/` | 타사 물류정책 리서치 | 정책 산정 근거 |
| `vision_model_docs/` | YOLO 학습 산출물(곡선·혼동행렬·배치 샘플) | 실험 증적 — `README.md`에 산출 모델과 조건 명시 |

`ai_knowledge_base/`는 문서가 아니라 **동작하는 데이터**입니다. 내용을 바꾸면 판정 근거가
바뀌므로, 수정 시 `app/core/rag_builder.py`로 임베딩을 재생성해야 합니다.
